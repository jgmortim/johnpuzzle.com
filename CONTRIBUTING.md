# Contributing to JohnPuzzle.com

This is my personal website. It's open source, but no one else should be working on the code. 
If you find a bug, you're welcome to open an issue, but pull requests will not be accepted.

This project adheres to the [SciActive Human Contribution Policy 2-NE](HUMAN-CONTRIBUTION-POLICY-2-NE.md).
